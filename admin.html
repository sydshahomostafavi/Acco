ACCO RIVERS / PRIVATE MANAGEMENT

پنل مدیریت محصولات ACCO

از موبایل، محصولات هر برند را اضافه یا ویرایش کن؛ عکس واقعی، گالری پروژه و کاتالوگ PDF بارگذاری کن و تغییرات را روی سایت اصلی منتشر کن.

🔐 این نسخه از اتصال مستقیم و محدود به GitHub استفاده می‌کند. رمز حساب GitHub را اینجا وارد نکن. فقط یک Fine-grained Personal Access Token مخصوص مخزن Acco با مجوز Contents: Read and write لازم است. توکن روی دستگاه ذخیره نمی‌شود و هنگام بستن صفحه از حافظه پاک می‌شود.
ساخت توکن محدود ↗

در صفحه ساخت توکن: Repository access = Only select repositories → Acco؛ Repository permissions → Contents = Read and write. برای امنیت بهتر تاریخ انقضای ۹۰ روزه بگذار و توکن را در Password Manager نگه دار. لطفاً توکن را برای هیچ‌کس ارسال نکن.
